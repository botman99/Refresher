# Refresher

Refresher is a Visual Studio Extension that will reload/refresh editor documents when the file is modified externally.

When using Refresher, turn off the internal Visual Studio document change detection by going to Tools -> Options then Environment -> Documents and uncheck 'Detect when file is changed outside the environment'

See the [Releases](https://github.com/botman99/Refresher/releases) page to download the latest release.
